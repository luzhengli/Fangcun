## 安装

```bash
brew install --cask luzhengli/fangcun/fangcun   # 桌面应用
brew install luzhengli/fangcun/fangcun          # 命令行 fangcun（从源码编译）
```

也可以直接下载下面的 dmg 和命令行压缩包，用 `SHA256SUMS` 核对。

**第一次打开**：这一版没有签名公证，macOS 会拦下。在「系统设置 → 隐私与安全性」里点「仍要打开」，之后照常使用。
